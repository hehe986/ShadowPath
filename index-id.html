Bukan sekadar daftar URL mentah.

Kebanyakan tool cuma memuntahkan ribuan baris. ShadowPath mengumpulkan dari banyak sumber, memvalidasi, lalu mengelompokkan berdasarkan sensitivitas dan aksesibilitas.

⧉

Passive Harvesting

Kumpulkan ribuan URL historis dari Wayback, Common Crawl, OTX, dan URLScan — tanpa menyentuh target.

◈

SPA-Aware Crawler

Render halaman JavaScript (React/Vue/Angular) via headless Chromium. Tangkap link + API endpoint dari XHR/fetch.

⊞

4-Way Classification

Pisahkan endpoint berdasarkan sifat (private/public) × aksesibilitas (open/closed). Context-aware, minim false positive.

⟁

Subdomain Enum

crt.sh, OTX, HackerTarget, Wayback, DNS bruteforce, dan permutation — digabung jadi satu peta lengkap.

◐

Stealth Layer

Rotasi User-Agent, jeda waktu Gaussian, header mimicry, dan noise interleaving untuk meniru pola manusia.

◫

Interactive Report

Laporan HTML yang bisa dicari & difilter, dengan badge kode status HTTP berwarna dan arsip per-scan.

getting started

Jalan dalam 3 baris.

Butuh Python 3.10+ dan git. Playwright opsional untuk render SPA.

Linux / macOS
Windows
First Scan
copy ⧉ # clone & install
git clone https://github.com/hehe986/ShadowPath
cd ShadowPath
pip install -r requirements.txt

# opsional: SPA rendering
pip install playwright && playwright install chromium
copy ⧉ # PowerShell
git clone https://github.com/hehe986/ShadowPath
cd ShadowPath
python -m pip install -r requirements.txt
copy ⧉ # crawl cepat di target latihan legal
python3 main.py -d testphp.vulnweb.com --crawl --max-pages 5

# harvest URL dari arsip publik
python3 main.py -d testphp.vulnweb.com --harvest --raw

// tentang project

ShadowPath dikembangkan sebagai engine reconnaissance modular untuk kebutuhan pentest dan bug bounty. Setiap komponen — dari stealth layer sampai klasifikasi endpoint — dirancang dan dibangun dari awal.

Tujuannya sederhana: menyaingi volume tool mainstream seperti gau dan katana, sambil menambahkan lapisan klasifikasi cerdas yang membuat hasil langsung bisa ditindaklanjuti.

⚠ Legal & Ethics

ShadowPath hanya untuk target dengan izin eksplisit: lab sendiri, CTF, atau program bug bounty yang in-scope. Penggunaan tanpa izin melanggar hukum — di Indonesia melalui UU ITE Pasal 30. Tool disediakan "sebagaimana adanya"; segala risiko dan tanggung jawab ada pada pengguna sepenuhnya.
