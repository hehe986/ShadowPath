capabilities

Not just a raw URL dump.

Most tools just spit out thousands of lines. ShadowPath gathers from many sources, validates, then groups results by sensitivity and accessibility.

⧉

Passive Harvesting

Collect thousands of historical URLs from Wayback, Common Crawl, OTX, and URLScan — without touching the target.

◈

SPA-Aware Crawler

Render JavaScript pages (React/Vue/Angular) via headless Chromium. Capture links + API endpoints from XHR/fetch.

⊞

4-Way Classification

Separate endpoints by nature (private/public) × accessibility (open/closed). Context-aware, minimal false positives.

⟁

Subdomain Enum

crt.sh, OTX, HackerTarget, Wayback, DNS bruteforce, and permutation — merged into one complete map.

◐

Stealth Layer

User-Agent rotation, Gaussian timing jitter, header mimicry, and noise interleaving to mimic human patterns.

◫

Interactive Report

A searchable, filterable HTML report with colored HTTP status badges and per-scan archives.

getting started

Running in 3 lines.

Requires Python 3.10+ and git. Playwright is optional for SPA rendering.

Linux / macOS
Windows
First Scan
copy ⧉ # clone & install
git clone https://github.com/hehe986/ShadowPath
cd ShadowPath
pip install -r requirements.txt

# optional: SPA rendering
pip install playwright && playwright install chromium
copy ⧉ # PowerShell
git clone https://github.com/hehe986/ShadowPath
cd ShadowPath
python -m pip install -r requirements.txt
copy ⧉ # quick crawl on a legal practice target
python3 main.py -d testphp.vulnweb.com --crawl --max-pages 5

# harvest URLs from public archives
python3 main.py -d testphp.vulnweb.com --harvest --raw

about

// about the project

ShadowPath was built as a modular reconnaissance engine for pentest and bug bounty work. Every component — from the stealth layer to endpoint classification — was designed and built from the ground up.

The goal is simple: match the volume of mainstream tools like gau and katana, while adding a smart classification layer that makes results immediately actionable.
